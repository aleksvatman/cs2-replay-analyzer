# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Состояние репозитория

Кода пока нет: только два документа (на русском), которые являются источником истины.

- `parser-doc.md` — спецификация крейта `parser-core` (формат JSON, структура, этапы). Работа сейчас идёт по ней.
- `plan.md` — план всего проекта (сервер на Axum, `ios-bridge`, iPad-приложение на SwiftUI). Парсер — лишь первая часть.

Команды сборки/тестов появятся после создания Cargo workspace (этап 1); до этого не придумывай их.

**Отклонение от спецификации:** по решению владельца в первую версию парсера входят позиция брошенной бомбы, статистика по игрокам и экономика (деньги, закупка, инвентарь). Документы (`parser-doc.md`, `plan.md`, `docs/format.md`) уже обновлены под это решение.

## Архитектура (planned)

`parser-core` — Rust-библиотека: `.dem` → компактный JSON для 2D-повтора. Один и тот же код должен собираться под сервер и под iOS (статическая библиотека через `ios-bridge`), поэтому:

- никаких зависимостей от Axum, Tokio, сети и платформенного кода; только `parser` (ядро demoparser2), `serde`, `serde_json`;
- API синхронный (тяжёлый по CPU); поток выбирает вызывающая сторона; публичная функция принимает путь или поток байтов + необязательный колбэк прогресса и возвращает `Result`;
- чтение должно быть потоковым (целевой iPad 7 с 3 ГБ памяти). Ядро demoparser2 это может не поддерживать — проверить по исходникам до того, как на этом строить.

Модули: `lib.rs` (интерфейс), `parse_demo.rs` (всё общение с demoparser2: события и тики), `extract.rs` (сырые данные → раунды, снимки, гранаты, бомба), `models.rs` (структуры serde = JSON-контракт), `error.rs`. Тесты — на маленькой демке с эталонным JSON из `samples/`; формат фиксируется в `docs/format.md`.

## Контракт JSON (важные инварианты)

- Обязательное `schemaVersion`; верхний уровень: `map`, `tickRate`, `players`, `weapons`, `rounds`.
- Снимки каждые 4 тика; в раунде один общий массив `ticks`, у каждого игрока массивы `x,y,z,yaw,pitch,hp` той же длины (индекс совпадает с `ticks`).
- Целые числа: координаты и углы в десятых долях; hp 0-100, `hp == 0` значит мёртв (отдельного флага нет).
- Команда хранится один раз на игрока; оружие — список смен `(индекс снимка, id)` + словарь `weapons`.
- События (убийства, урон, ослепления, раунды) — отдельные короткие списки с тиком в каждой записи.
- Гранаты: траектория шагом 4 тика, точки отскока (bounce) — отдельные точки со своим тиком.
